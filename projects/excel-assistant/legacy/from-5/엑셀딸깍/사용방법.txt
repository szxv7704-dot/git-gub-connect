엑셀딸깍 1.1.0

[사용 순서]
1. 기준 서식에서 최종 결과에 사용할 엑셀 파일과 표를 선택합니다.
2. 파일 취합에서 제출받은 엑셀/CSV 파일을 여러 개 추가합니다.
3. 자동 연결 결과를 확인하고 잘못 연결된 열은 직접 수정합니다.
4. 데이터 작업에 표시된 '데이터가 있는 열'을 확인하고 원하는 작업을 자연어로 입력합니다.
5. 프로그램이 이해한 작업과 미리보기를 확인합니다.
6. 결과 만들기에서 저장합니다.

[개인정보 보호]
모든 파일 처리와 자연어 해석은 이 PC에서만 수행됩니다.
인터넷, 외부 AI, 서버, API로 엑셀 내용을 보내지 않습니다.

[지원 파일]
.xlsx / .xlsm / .csv
구형 .xls 파일은 Excel에서 .xlsx로 다시 저장한 뒤 사용해 주세요.

[요청 예시]
- 기관별 예산액과 집행액을 합산하고 집행률을 계산해서 큰 순서대로 순위를 정해줘
- 집행률이 80% 미만인 행만 추출해줘
- 부서별 합계를 큰 순서대로 정렬하고 순위를 정해줘
- 사업명 중복 항목을 찾아줘
- 예산액에서 집행액을 뺀 잔액을 추가해줘

[중요]
프로그램이 표시하는 '이해한 작업'과 결과 미리보기를 확인한 뒤 저장하세요.
애매한 요청은 임의로 실행하지 않고 오류로 안내합니다.
병합 셀과 지역·기관·부서·사업 열의 반복 생략값은 자동으로 복원합니다.
빈 그룹 값은 'None'이라는 항목으로 만들지 않고 제외 건수로 표시합니다.

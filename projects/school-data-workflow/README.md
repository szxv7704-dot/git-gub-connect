# 학교 자료 취합 도우미

여러 학교가 보낸 Excel·CSV 파일을 한 흐름에서 취합하고, 선택적으로 개인정보를 보호한 뒤, 말로 요청한 정리 작업을 적용하는 Windows 데스크톱 프로그램입니다. 모든 처리는 사용자 PC에서 이루어지며 원본 파일을 덮어쓰지 않습니다.

## 처리 흐름

1. 여러 `.xlsx`, `.xlsm`, `.csv` 파일을 열 이름에 맞춰 아래로 취합합니다.
2. 취합 결과를 미리 보고 단계 결과를 `.xlsx`로 저장합니다.
3. 개인정보 후보 열마다 `처리 안 함`, `부분 마스킹`, `완전 마스킹`, `열 삭제` 중 하나를 선택합니다.
4. 마스킹 결과에서 변경된 셀을 색으로 확인하고, 마우스를 올려 처리 전후를 비교합니다.
5. 데이터 정리 요청을 입력하고 프로그램이 해석한 실행 계획을 확인합니다.
6. 정리 결과를 미리 보고 각 단계 또는 최종 결과를 저장합니다.

서로 다른 열 순서와 공백·대소문자가 다른 열 이름은 정규화해 맞춥니다. 실제로 없는 열과 추가된 열은 경고로 표시하고, 빠진 값은 빈칸으로 둡니다.

## 자연어 정리의 원칙

이 기능은 임의의 코드를 생성하거나 백데이터에 저장된 정확한 문장만 비교하지 않습니다. 현재 파일의 실제 열 이름을 먼저 찾은 뒤 다음의 검증 가능한 작업을 조합합니다.

- 공백 정리, 날짜·숫자 형식 통일, 값 바꾸기
- 빈칸 찾기 또는 빈칸 행 제거
- 한 개 이상 열 기준 중복 제거
- 오름차순·내림차순 정렬
- 하나 이상의 그룹 열을 기준으로 합계·평균·개수 계산

예: `부서와 정책사업별 합계를 합산하고 큰 순서로 정렬해줘`

해석할 수 없거나 대상 열을 특정하지 못한 요청은 추측 실행하지 않습니다. UI의 실행 계획과 신뢰도를 보고 열 이름을 포함해 다시 작성해야 합니다. 이 제한은 잘못된 합계가 정상 결과처럼 저장되는 것을 막기 위한 의도적인 안전장치입니다.

## 실행 및 테스트

```powershell
python -m pip install -r requirements.txt
python ui.py
```

```powershell
python -m pip install pytest
python -m pytest tests -q
```

Windows 실행 파일은 프로젝트 폴더에서 다음 명령으로 만듭니다.

```powershell
.\build.ps1
```

결과는 저장소 루트의 `dist\학교자료취합도우미.exe`에 생성됩니다. 실행 파일과 실제 학교 자료는 Git에 커밋하지 않습니다.

## 검증 자료와 참고 방향

- K-지방직 정책서랍의 정선군 2026 공개 예산 구조화 자료 3천 행 이상을 두 통합문서로 나누어 취합·다중 그룹 합산·정렬·저장·재열기까지 검증합니다.
- K-지방직에서 내려받은 공개 PDF는 Excel 파일로 오인하지 않고 지원 형식을 명확히 안내하는지 별도로 확인합니다.
- VHLookup의 단계별 Excel 도구 흐름, Nothing과 KID의 탐지 후 사용자 검토 원칙, Excel 딸깍의 작은 결정형 작업 조합 방식을 제품 방향으로 참고했습니다.

외부 프로젝트의 소스 코드는 포함하지 않았습니다. Nothing과 KID는 AGPL 계열이고, VHLookup은 확인 당시 명시적 라이선스를 찾기 어려워 아이디어와 검토 원칙만 참고했습니다.

## 개인정보 주의

- 자동 탐지는 완벽하지 않습니다. 저장 전에 모든 후보 열과 마스킹 미리보기를 사람이 확인해야 합니다.
- 결과 파일명이나 로그에 원래 개인정보 값을 기록하지 않습니다.
- 실제 개인정보가 든 원본·결과·실행 중 생성된 파일은 Git에 올리지 않습니다.

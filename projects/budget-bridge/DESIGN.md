# 예산 검토 도우미 디자인 기준

## Direction
Flat 2.0와 Line art를 사용한다. 교육행정 담당자가 자료와 금액의 관계를 이해하도록 둥근 조작부와 곡선 연결선을 결합한다. 곡선은 흐름과 조작 가능성을 표현하는 데 사용한다. 장식적인 대시보드나 홍보용 랜딩 페이지로 확장하지 않는다.

## Palette
사용자가 지정한 색을 기준으로 한다. ground #F5F7FA는 긴 작업의 눈부심을 줄이는 배경, panel #FFFFFF는 입력과 안내 표면, ink #243447은 한글 본문의 대비, accent #387C9C는 다음 행동과 현재 단계, good #278579는 선택 완료와 일치 상태이다. 보조 muted #657486과 line #DEE6EC는 정보 위계를 분리한다. 경고 #94610E와 오류 #B43B45는 구현 시 아이콘·문구와 함께 사용하고 accent와 구분한다.

## Type
맑은 고딕은 Windows 기본 한글 본문·제목 글꼴이며 폰트 배포 없이 기존 업무환경에 맞춘다. 숫자 표에는 Consolas와 tabular-nums를 적용해 자릿수를 맞춘다. 제목 28/700, 영역 20/700, 본문 14/400, 보조 13 또는 12/400, 상태 배지 11/400. 화면 폭이 줄어도 핵심 본문을 먼저 숨기거나 작게 만들지 않고 줄바꿈한다. 설명 문장은 대략 65자 이내로 나눈다.

## Spacing and shape
8px 간격 단위. 영역 사이 24~32px, 내부 16~24px. 버튼 반경 13px, 자료 영역 18px, 말풍선 16px, 컨테이너 20px. 각각 클릭·묶음·안내라는 역할 차이를 표현한다. 테두리 1px, 연결선 2px. 버튼 높이 최소 44px. 파일 선택 버튼은 매 행 같은 위치에 둔다.

## Components
사용법 안내 말풍선은 작업 카드와 색을 뒤집는다: 바탕 ink #243447, 제목 흰색, 본문 #D5E0E8, 머리표 #8FD3C8, 위쪽 꼭지로 설명하는 칸을 가리킨다. 안내와 작업 표면이 같은 흰 카드면 구분되지 않는다(2.16.0). 팝오버 Popover는 한 번에 하나 표시하고 제목과 설명을 접근성 속성으로 연결한다. 실제 위치를 기준으로 재배치하며 Escape로 닫고 실행한 버튼으로 초점을 돌린다. 스텝퍼 Stepper는 순서 목록과 aria-current로 현재 단계를 표현한다. 목적 2는 양방향 실선, 목적 3은 입력→출력 실선과 서식 참고 점선으로 구분한다. 작업 순서의 단계 사이 화살표는 곧은 3px 선과 큰 촉으로 그리고 색으로 상태를 말한다(끝냄 good · 다음 accent · 아직 #8FA7B8). 가늘고 연한 물결선은 흐름으로 읽히지 않았다(2.16.0). 파일 선택 완료는 체크·파일명을 함께 표시한다. 버튼은 기본·호버 140ms·초점 테두리·비활성 상태를 갖춘다. 하단 실행부는 고정한다. 움직임 줄이기는 시스템 설정과 화면 설정 둘 다 지원한다.

## Voice
자료명은 사업설명서로 통일한다. 동작 버튼은 결과를 설명하는 동사를 쓴다. 기본 화면은 자료명·용도·선택 상태, 긴 설명은 해당 위치의 안내에 배치한다. 예시 실행에는 실제 검토 결과를 표시하지 않는다.

## Anti slop
크림색과 세리프 조합, 보라색 그라데이션, 네온 강조, 이모지 섹션 아이콘, 전체 중앙정렬, 모든 표면에 같은 반경 적용, 무의미한 통계 카드는 사용하지 않는다. 사용자 팔레트와 실제 자료의 관계가 시각적 기준이다.

## 구현 범위
ui_preview는 백엔드에 연결하지 않은 독립 HTML 시안이다. 기존 Python 및 dist_ui EXE는 이번 단계에서 수정하지 않는다. 현재 입력 행은 converter.Session.output_rows가 사업설명서 프로젝트에서 생성하고 edufine_form.write_form이 지난 입력본 서식에 기록한다. UBIS 직접 변환은 추가 구현 대상이며 완성 기능으로 안내하지 않는다.

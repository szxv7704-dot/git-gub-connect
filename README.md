# 자동화프로그램

집과 회사 노트북에서 공유하는 개인 자동화 프로젝트 저장소입니다.

## 프로젝트

- `projects/excel-assistant`: 여러 엑셀·CSV 자료를 분석하고 합계, 필터, 정렬, 중복, 합계 검증을 수행하는 도구

## 작업 원칙

- 소스와 테스트만 저장소에 보관합니다.
- 실행 파일, 결과 파일, 개인정보가 포함된 원본 자료는 저장하지 않습니다.
- 작업 전 `git pull`, 작업 후 테스트·커밋·푸시를 수행합니다.
- Claude와 ChatGPT 모두 변경 전후 테스트 결과를 기록합니다.

## 브랜치

- `main`: 검증된 기준 버전
- `topic/excel-assistant`: 엑셀 자동화 프로젝트
- `topic/validation`: 공개 예산자료 기반 검증
- `topic/release`: 빌드·배포 설정
